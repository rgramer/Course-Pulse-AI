### Exact Invite Behavior Locked

| Aspect | Locked Behavior |
|--------|----------------|
| **Auth** | Bearer token, active profile, `role = owner_admin`, non-null `company_id` |
| **Request** | `{ email, role }` — email trimmed + lowercased |
| **Allowed V1 roles** | `office`, `technician` only (not `owner_admin`) |
| **DB write** | One `user_invites` row: `company_id` from profile, normalized `email`, requested `role`, `invited_by` = profile id, `invite_token_hash` (never raw token), `status = 'pending'`, `expires_at` = 7 days |
| **Token** | High-entropy, hash stored, raw returned once in response |
| **Duplicates** | `409 conflict` if pending non-expired invite exists for same company + email |
| **Response** | `{ data: { invite_id, email, role, status, expires_at, invite_token, invite_url } }` |
| **Errors** | `401 unauthenticated`, `404 not_found`, `403 permission_denied`, `400 validation_error`, `409 conflict` |
| **Out of scope** | Accept-invite, signup, password, real email, profile creation, onboarding, frontend, notifications, deployment |
